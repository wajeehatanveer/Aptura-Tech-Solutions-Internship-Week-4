# Aptura Tech Solutions — Python Internship | Week 4
### Task 1 — Help Desk / Support Ticket Management System

## 📌 Overview

A professional Python-based Help Desk / Support Ticket Management System built to manage support tickets, staff, assignments, ticket updates, and reports.

## ✨ Features

- 🎫 Create, view, update, and manage support tickets
- 👥 Manage staff records and ticket assignments
- 📊 Generate ticket reports
- 💾 SQLite persistent database
- ✅ Input validation
- 🛡️ Exception handling
- 📝 Application logging
- 🧪 Automated testing with Pytest
- 🖥️ User-friendly Streamlit interface
- 🏗️ Modular project architecture

## 🛠️ Technologies

- Python
- Streamlit
- SQLite
- Pytest
- Dataclasses
- Logging

## ▶️ Run the Project

Install dependencies:

```bash
pip install -r requirements.txt
```

### Run the Streamlit application

```bash
streamlit run app.py
```
